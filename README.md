# Fake Notifs

Android app with a library of fake notifications. Send now, after a delay, or at a set time.
Pick the app to imitate from your installed apps (name and icon are copied), or attach your own icon and picture.

## Build with GitHub

1. Create a new GitHub repo and push this folder to the `main` branch.
2. Open the repo's **Actions** tab. The "Build APK" workflow runs on every push (or press "Run workflow").
3. When it finishes, open the run and download the **FakeNotifs-debug-apk** artifact.
4. Unzip it and install `app-debug.apk` on your phone (allow "install unknown apps").

On first launch, allow notifications.
